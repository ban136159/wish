# 《雾钟》代码结构与阅读指南

本文对应 Unity 项目的基础脚本，帮助初学者理解每个脚本的职责、主要调用关系和 Inspector 配置。

## 1. 脚本目录

| 路径 | 职责 |
| --- | --- |
| `Assets/Scripts/Player/PlayerController.cs` | 读取方向输入并通过 Rigidbody2D 移动玩家 |
| `Assets/Scripts/Interaction/IInteractable.cs` | 定义可交互对象需要实现的统一接口 |
| `Assets/Scripts/Interaction/PlayerInteractor.cs` | 检测玩家附近的可交互对象，按 E 执行交互 |
| `Assets/Scripts/Interaction/ClueInteractable.cs` | 将调查物体转换为可登记的线索 |
| `Assets/Scripts/Dialogue/DialogueLine.cs` | 保存说话者名称和对话文本 |
| `Assets/Scripts/Dialogue/DialogueManager.cs` | 开始、推进和结束对话，并通过事件通知 UI |
| `Assets/Scripts/Inventory/ClueJournal.cs` | 保存本次运行期间收集的线索，阻止重复 ID |
| `Assets/Scripts/TimeLoop/TimeLoopManager.cs` | 推进游戏内日期，并在循环结束时进入新一轮 |
| `Assets/Scripts/Core/GameManager.cs` | 提供简单的全局单例入口，并跨场景保留对象 |

## 2. 主要调用流程

### 玩家移动
1. `PlayerController.Update()` 读取 Horizontal / Vertical 输入。
2. 输入方向归一化，避免斜向移动速度更快。
3. `FixedUpdate()` 将速度设置到 Rigidbody2D。

### 调查线索
1. `PlayerInteractor` 使用 OverlapCircleAll 检测指定 Layer 的碰撞体。
2. 检测器从碰撞体及其父物体上查找 `IInteractable`。
3. 按 E 时调用目标的 `Interact()`。
4. `ClueInteractable` 查找 `ClueJournal` 并调用 `AddClue()`。
5. 新线索添加成功后触发 `ClueAdded` 事件，可供日志 UI 订阅。

### 对话播放
1. 调用 `StartDialogue(lines)` 开始对话。
2. `LineChanged` 事件通知 UI 显示当前句子。
3. 按 E 或空格调用 `Advance()`。
4. 全部句子播放完成后关闭面板并触发 `DialogueEnded`。

### 七日循环
1. `TimeLoopManager.Update()` 按现实时间累计一天的进度。
2. 达到一天长度后调用 `AdvanceDay()`。
3. 普通日期触发 `NewDayStarted`。
4. 到达本轮末日后，循环数加一、日期回到第一天，并触发 `LoopRestarted` 和 `NewDayStarted`。

## 3. Unity Inspector 配置提示

- **Player**：添加 `Rigidbody2D`、`Collider2D` 和 `PlayerController`。俯视角场景应将 Gravity Scale 设为 0，并避免刚体旋转。
- **PlayerInteractor**：可选设置 `Interact Point`；将可调查物体放入指定 Layer，并配置 `Interactable Layers`。
- **ClueInteractable**：为每个线索填写唯一的 `Clue Id`、标题和描述。
- **ClueJournal**：场景中需要有一个挂载该组件的对象，否则线索无法登记。
- **DialogueManager**：将 Canvas 中的对话面板拖到 `Dialogue Panel`，并在 Inspector 配置对话数组。UI 需要订阅 `LineChanged` 来更新文本。
- **TimeLoopManager**：设置 `Days Per Loop` 和 `Day Length Seconds`；一天的最短长度由代码限制为 10 秒。

## 4. 当前实现边界

这些脚本是基础框架，不代表完整游戏系统：
- `ClueJournal` 目前只在运行时保存数据，没有持久化存档。
- `TimeLoopManager` 只负责日期和事件，不会自动重置 NPC、线索或场景状态。
- `DialogueManager` 提供事件，但不直接绑定具体的文本 UI 组件。
- `GameManager` 当前只有单例生命周期管理，没有加入任务、音频或存档功能。

## 5. 阅读建议

建议先读 `PlayerController`，再读 `IInteractable` 和 `PlayerInteractor`，接着看 `ClueInteractable` 与 `ClueJournal`，最后阅读对话和时间循环脚本。脚本中的中文注释解释字段用途、Unity 生命周期方法以及事件触发时机。
