# 《雾钟》2D 主角摄像机设置（HD-2D 过渡阶段）

当前主角使用 SpriteRenderer / Rigidbody2D，仍处于 Unity 的 XY 平面。本脚本先解决 2D 跟随；它不会把 2D 主角自动变成 3D，也不会单独生成 3D 建筑。

## 1. 导入
把 `Assets/Scripts/Camera/WuzhongCameraFollow2D.cs` 放进 Unity 项目，等待编译完成。

## 2. Main Camera 参数
- Projection: Orthographic
- Position: (0, 0, -10)
- Rotation: (0, 0, 0)
- Orthographic Size: 5（数值越大，画面看到的范围越大）
- Clipping Planes: Near 0.1 / Far 1000
- Background: 深灰蓝色，例如 RGB 18, 24, 35

## 3. 挂载脚本
1. 选中 Main Camera，Add Component → WuzhongCameraFollow2D。
2. 将 Hierarchy 中的 Player 拖到 Target。
3. 初始参数建议：Offset (0, 0.8, -10)，Smooth Time 0.18，Look Ahead Distance 0.6。
4. 按 Play，测试上下左右移动。若镜头晃动或追得太慢，把 Smooth Time 调到 0.12；若镜头太灵敏，调到 0.22。

## 4. Rigidbody2D 兼容提示
脚本读取 Rigidbody2D.linearVelocity（适用于 Unity 6）。如果你的 Unity 版本较旧且报错“Rigidbody2D 不包含 linearVelocity”，将代码中的 `targetBody.linearVelocity` 替换成 `targetBody.velocity`。

## 5. 下一步：HD-2D 的正确路线
保留现有 2D 主角和 Rigidbody2D，先完成摄像机构图与 2D 灰盒测试。若最终要真正的 3D 斜俯视村落，建议后续新建独立 3D 场景：3D 地面和建筑放在 XZ 平面，2D 精灵用专门的朝向/排序方案面向摄像机；不要直接把当前 2D 摄像机旋转 50 度，否则精灵会倾斜且物理仍在 XY 平面。
