# 《雾钟》四方向主角接入说明

玩家控制器支持分别指定前、后、左、右四张角色图片，并在移动时自动切换方向。上下起伏和倾斜已调低，静止时仅保留极轻微呼吸；可在 Inspector 中设为 0 关闭。

## 1. 准备四方向图片

准备四张透明背景 PNG，分别为：
- `shenyan_front.png`：面向屏幕下方/正面
- `shenyan_back.png`：面向屏幕上方/背面
- `shenyan_left.png`：向左
- `shenyan_right.png`：向右

放入 `Assets/Art/Characters/Player/`。如果使用一张图集，请先在 Unity 中切片：
1. 选中图集 PNG，在 Inspector 设置 Texture Type 为 `Sprite (2D and UI)`、Sprite Mode 为 `Multiple`。
2. 点击 Sprite Editor，将图集切成独立 Sprite 并 Apply。
3. 如果是四张单独的 PNG，Sprite Mode 使用 `Single` 即可。

像素风图片建议 Filter Mode 为 `Point (no filter)`、Compression 为 `None`，完成后点击 Apply。

## 2. 配置 Player

1. 选中场景中的 Player Prefab，确认根对象有 `Rigidbody2D`、`Collider2D` 和 `PlayerController`。
2. Rigidbody2D 的 Gravity Scale 设为 `0`，Freeze Rotation Z 开启。
3. 在 PlayerController Inspector 的「四方向图片」栏，将四张 Sprite 分别拖入 Front Sprite、Back Sprite、Left Sprite、Right Sprite。
4. 若某个方向未设置，脚本会保留当前图片；建议四个方向全部设置，避免方向外观不一致。
5. 点击 Play，用 WASD 或方向键测试。按住对角线时，脚本会根据输入幅度较大的轴选择方向；松开按键后会保留最后朝向。

## 3. 晃动设置

默认值已经调低：
- Move Speed：`3.5`
- Walk Bob Amount：`0.012`（移动起伏幅度）
- Walk Bob Speed：`9`
- Idle Bob Amount：`0.001`（静止呼吸幅度）
- Idle Bob Speed：`1.5`
- Tilt Amount：`0.5`（横向移动倾斜角度）

如果仍觉得晃动明显，可将 Walk Bob Amount、Idle Bob Amount 和 Tilt Amount 全部设为 `0`。

## 4. 注意事项

- 控制器使用旧版 Input Manager 的 `Horizontal` 和 `Vertical` 输入轴。如果项目只启用了新版 Input System，请在 Project Settings 中将 Active Input Handling 设为 `Both` 或 `Input Manager (Old)`。
- 脚本会把根对象上的 SpriteRenderer 迁移到运行时的 `PlayerVisual` 子对象，让视觉晃动不影响 Rigidbody2D。
- 此次修改只完成方向图片切换逻辑，不会自动生成四张独立美术图；需要把你制作或导入的四张 Sprite 指定到 Inspector。
