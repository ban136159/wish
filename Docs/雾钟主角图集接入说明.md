# 《雾钟》单张 PNG 主角接入说明

本项目主角控制器已改为使用**单张角色 PNG**，不再依赖 4×4 Sprite Sheet、16 张切片或逐帧动画。移动效果通过角色图片的轻微上下起伏和倾斜模拟。

## 1. 导入角色图片

1. 将透明背景的单张角色 PNG 放到 `Assets/Art/Characters/Player/`，例如 `shenyan.png`。
2. 在 Unity Project 窗口选中图片，在 Inspector 中设置：
   - Texture Type：`Sprite (2D and UI)`
   - Sprite Mode：`Single`
   - Pixels Per Unit：按图片像素尺寸设置，像素风项目可从 `48` 开始
   - Filter Mode：`Point (no filter)`
   - Compression：`None`
3. 点击 Apply。

## 2. 设置玩家对象

1. 将 PNG 拖进场景创建角色对象，或给现有 Player 对象添加 SpriteRenderer 并指定这张 PNG。
2. 在 Player 根对象上添加 `Rigidbody2D`、合适的 `Collider2D` 和 `PlayerController`。
3. Rigidbody2D 的 Gravity Scale 设为 `0`，Freeze Rotation Z 开启。
4. 如果 SpriteRenderer 挂在根对象上，脚本会在运行时创建 `PlayerVisual` 子对象并迁移图片渲染设置，让晃动效果不会干扰 Rigidbody2D 的物理移动。
5. 点击 Play，使用 WASD 或方向键移动。

## 3. 调整晃动效果

在 PlayerController Inspector 中可调整：

- Move Speed：移动速度，默认 `3.5`
- Walk Bob Amount：行走上下起伏幅度，默认 `0.045`
- Walk Bob Speed：行走起伏速度，默认 `12`
- Idle Bob Amount：静止呼吸幅度，默认 `0.008`
- Idle Bob Speed：静止呼吸速度，默认 `2`
- Tilt Amount：横向移动时的倾斜角度，默认 `2`

建议像素风角色使用较小的起伏和倾斜值，避免画面显得抖动或倾倒。

## 4. 注意事项

- 单张 PNG 只能模拟整体晃动，无法呈现真实的腿部交替、四方向外观变化。
- 控制器使用旧版 Input Manager 的 `Horizontal` 和 `Vertical` 输入轴。如果项目只启用了新版 Input System，需要在 Project Settings 中启用 `Both` 或 `Input Manager (Old)`，或改写输入代码。
- 本控制器使用 Rigidbody2D 处理移动；碰撞边界请通过 Collider2D 设置。
