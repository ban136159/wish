# 《雾钟》主角像素图集接入说明

## 图集规格
- PNG：192×256 px，透明背景；4 列×4 行，每帧 48×64 px。
- 从上到下：向下、向左、向右、向上；每行从左到右为站立帧与 3 帧行走循环。
- 当前为基础移动图集，不包含攻击、受伤、死亡动画。

## Unity 导入
1. 将图集放到 `Assets/Art/Characters/Player/wuzhong_player_atlas.png`。
2. Texture Type = Sprite (2D and UI)，Sprite Mode = Multiple，Pixels Per Unit = 48，Filter Mode = Point (no filter)，Compression = None。
3. Sprite Editor → Slice → Grid By Cell Size，Cell Size X = 48、Y = 64；Pivot 建议 Bottom Center；点击 Slice、Apply。
4. 在 PlayerController 的 Character Frames 数组中，按图集从上到下、每行从左到右的顺序拖入 16 张切片。
5. Player 需要 Rigidbody2D（Gravity Scale = 0、Freeze Rotation Z）和合适的 Collider2D；脚本可自动查找或添加 SpriteRenderer。
6. 当前控制器使用旧版 Input Manager 的 Horizontal/Vertical 输入轴。若项目只启用了新版 Input System，需要调整输入读取方式。

控制器直接按帧切换 Sprite，不依赖 Animator Controller。Unity 6 使用 Rigidbody2D.linearVelocity，较早版本使用 Rigidbody2D.velocity。
