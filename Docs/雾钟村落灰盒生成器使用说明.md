# 《雾钟》第一版 2D 村落灰盒生成器

此工具是为当前仍使用 `SpriteRenderer + Rigidbody2D`、位于 XY 平面的主角准备的。它生成的是 2D 灰盒，不会旋转摄像机或改动主角，避免破坏当前已经正常的跟随。

## 安装与使用
1. 确保文件位于 `Assets/Editor/Wuzhong2DVillageBlockoutGenerator.cs`。如果没有 `Editor` 文件夹，请先创建。
2. 等 Unity 编译完成。
3. 在菜单选择 **Tools > Wuzhong > Generate 2D Village Blockout**。
4. 确认生成。Hierarchy 会出现 `WuzhongVillage_Blockout`。
5. 点击 Play 检查主角是否仍正常移动、摄像机是否跟随。
6. 需要保留场景时按 Ctrl+S 保存当前场景为新场景文件。

## 生成内容
- 深色背景地面与分块石板路
- 两栋老宅灰盒（墙、屋顶、门窗）
- 远处祠堂灰盒
- 两侧院墙与三棵简化古树
- 红灯笼色块标记
- 主角起始位置参考线

## 注意
- 工具只替换名为 `WuzhongVillage_Blockout` 的上一次生成对象，不会删除主角或摄像机。
- 这是 2D XY 灰盒，不是真正的 3D HD-2D 场景；下一步再逐步换成正式素材。
- 若场景里有多个摄像机，请确认只有一台启用的主摄像机。
